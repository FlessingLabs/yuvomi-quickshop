# Einkaufszettel – User guide

[Deutsch](ANLEITUNG.md) · **English**

Einkaufszettel is your household's list of things you buy again and again. Create an item **once**, then put it on the shopping list with **one tap**.

You find Einkaufszettel in Yuvomi's navigation under **Einkaufszettel**.

## The page at a glance

```text
┌───────────────────────────────────────────┐
│ Einkaufszettel                Target: Weekly shop │  ← everything goes onto this list
│ ┌───────────────────────────────────────┐ │
│ │ Search or create an item …            │ │  ← search AND create
│ └───────────────────────────────────────┘ │
│ Eggs                                (+)   │  ← tap the name = edit
│ 2× · €2.49                                │     (+) = put on the list
│ Milk                                (+)   │
│ 2× · €1.19                                │
└───────────────────────────────────────────┘
```

## Create an item

1. Type the name into the field at the top, for example `Oats`.
2. If the item does not exist yet, **Create "Oats"** appears. Tap it or press **Enter**.
3. Done. The item has a default quantity of 1 and no price. You can change both later.

Each name exists only once. "Milk" and "milk" count as the same item.

## Put it on the shopping list

Tap the round **+** next to the item. It goes onto the shopping list with its default quantity. A short confirmation appears at the bottom.

It is even quicker from the search field: type the name and press **Enter**. If the name matches an item exactly, it goes straight onto the list.

You can tap as many items as you like, one after another.

### What if the item is already on the list?

No second row appears. Instead:

| The shopping list has … | Einkaufszettel turns it into … |
|---|---|
| `Milk 1`, not bought yet | `Milk 3` (1 + default quantity 2) |
| `Milk`, already checked off | `Milk 2`, open again |
| `Milk 1 l` (quantity with a unit) | nothing. You only see the notice "already on the list" |

### Tapped the wrong one?

The confirmation at the bottom has an **Undo** button. One tap puts the shopping list back the way it was.

## Edit an item

1. Tap the item's **name**. The edit area opens below it.
2. Change what you need:
   - **Name**
   - **Default quantity** with **−** and **+**: this many go onto the list with each tap.
   - **Price** (optional), for example `1.99`. It is for your reference only and is not copied to the shopping list.
3. Tap **Save**. **Cancel**, or tapping the name again, closes the area without changes.

## Delete an item

Tap the item, then **Delete**. If it was a mistake, tap **Undo** in the confirmation at the bottom. Deleting does not change the shopping list.

## Several shopping lists

If you have more than one list, a selector appears at the top right. Choose where the items should go. Each device remembers its choice.

## Search

Just type: the list immediately shows only matching items. Part of the name is enough, `milk` also finds "Oat milk". **Esc** or the **×** in the field clears the search.

## Frequently asked questions

**There is no + next to the items.**
You may not edit the shopping list, or there is no shopping list yet. A notice at the top of the page tells you which.

**I cannot create or change items.**
Einkaufszettel is view-only for you. An admin can change this under *Settings → Household → Roles & permissions → Einkaufszettel*.

**"This Yuvomi has no module storage"**
Einkaufszettel 2 needs a Yuvomi version with module storage. Let your admin know: they can install that Yuvomi, or use Einkaufszettel 1.1 on an unmodified Yuvomi.

**"Somebody just changed this item"**
Somebody else saved the same item just before you. Einkaufszettel now shows their version. Check it and save your change again if you still want it; nothing is overwritten without asking.

**Does everyone in the household see the same catalogue?**
Yes. The catalogue belongs to the whole household, just like the shopping list.

## Open the finished shopping list

Tap **Open shopping list** at the top. This opens Yuvomi’s existing shopping page at `/shopping`, where you can check off the items while shopping.
