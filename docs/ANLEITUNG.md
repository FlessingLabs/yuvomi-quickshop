# QuickShop – Anleitung

**Deutsch** · [English](GUIDE.md)

QuickShop ist euer Merkzettel für Dinge, die ihr immer wieder kauft. Ihr legt einen Artikel **einmal** an und setzt ihn danach mit **einem Tipp** auf die Einkaufsliste.

Ihr findet QuickShop in Yuvomi in der Navigation unter **QuickShop**.

## Die Seite auf einen Blick

```text
┌───────────────────────────────────────────┐
│ QuickShop                Ziel: Wocheneinkauf │  ← auf diese Liste kommt alles
│ ┌───────────────────────────────────────┐ │
│ │ Artikel suchen oder neu anlegen …     │ │  ← suchen UND anlegen
│ └───────────────────────────────────────┘ │
│ Eier                                (+)   │  ← Name antippen = bearbeiten
│ 2× · 2,49 €                               │     (+) = auf die Liste
│ Milch                               (+)   │
│ 2× · 1,19 €                               │
└───────────────────────────────────────────┘
```

## Einen Artikel anlegen

1. Den Namen ins Feld oben tippen, z. B. `Haferflocken`.
2. Gibt es den Artikel noch nicht, erscheint **„Haferflocken“ anlegen**. Darauf tippen oder **Enter** drücken.
3. Fertig. Der Artikel hat die Standardanzahl 1 und keinen Preis. Beides könnt ihr später ändern.

Jeden Namen gibt es nur einmal. „Milch“ und „milch“ gelten als derselbe Artikel.

## Auf die Einkaufsliste setzen

Tippt auf das runde **+** neben dem Artikel. Er landet mit seiner Standardanzahl auf der Einkaufsliste. Unten erscheint kurz eine Bestätigung.

Schneller geht es über die Suche: Namen tippen, **Enter** drücken. Passt der Name genau zu einem Artikel, kommt er sofort auf die Liste.

Ihr könnt beliebig viele Artikel nacheinander antippen.

### Was passiert, wenn der Artikel schon auf der Liste steht?

Es entsteht keine zweite Zeile. Stattdessen:

| Auf der Einkaufsliste steht … | QuickShop macht daraus … |
|---|---|
| `Milch 1`, noch nicht gekauft | `Milch 3` (1 + Standardanzahl 2) |
| `Milch`, schon abgehakt | `Milch 2`, wieder offen |
| `Milch 1 l` (Menge mit Einheit) | nichts. Ihr seht nur den Hinweis „steht schon auf der Liste“ |

### Vertippt?

In der Bestätigung unten steht **Rückgängig**. Ein Tipp darauf stellt die Einkaufsliste wieder so her, wie sie vorher war.

## Einen Artikel ändern

1. Auf den **Namen** des Artikels tippen. Darunter klappt das Bearbeitungsfeld auf.
2. Ändern, was ihr möchtet:
   - **Name**
   - **Standardanzahl** mit **−** und **+**: so viele kommen bei jedem Tipp auf die Liste.
   - **Preis** (freiwillig), z. B. `1,99`. Er dient nur zur Orientierung und wird nicht in die Einkaufsliste übernommen.
3. **Speichern** tippen. **Abbrechen** oder ein erneuter Tipp auf den Namen schließt das Feld ohne Änderung.

## Einen Artikel löschen

Artikel antippen, dann **Löschen**. Ein Versehen macht ihr mit **Rückgängig** in der Bestätigung unten wieder gut. Auf der Einkaufsliste ändert das Löschen nichts.

## Mehrere Einkaufslisten

Habt ihr mehr als eine Liste, steht oben rechts eine Auswahl. Wählt dort, wohin die Artikel sollen. Jedes Gerät merkt sich seine Wahl.

## Suchen

Einfach tippen: Die Liste zeigt sofort nur noch passende Artikel. Es reicht ein Teil des Namens, `milch` findet auch „Hafermilch“. Mit **Esc** oder dem **×** im Feld wird die Suche geleert.

## Häufige Fragen

**Ich sehe kein + neben den Artikeln.**
Ihr dürft die Einkaufsliste nicht bearbeiten, oder es gibt noch keine Einkaufsliste. Ein Hinweis oben auf der Seite sagt, was davon zutrifft.

**Ich kann keine Artikel anlegen oder ändern.**
Für euch ist QuickShop nur zum Ansehen freigegeben. Ein Admin kann das unter *Einstellungen → Haushalt → Rollen & Berechtigungen → QuickShop* ändern.

**„QuickShop-Dienst nicht erreichbar“**
Prüft zuerst, ob ihr Yuvomi über die richtige Adresse geöffnet habt (die mit QuickShop, z. B. Port 8088). Hilft das nicht, liegt das Problem beim Server. Sagt eurem Admin Bescheid.

**Sehen alle im Haushalt denselben Katalog?**
Ja. Der Katalog gehört dem ganzen Haushalt, genau wie die Einkaufsliste.
