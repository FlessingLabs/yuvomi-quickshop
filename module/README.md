# FlessingLabs QuickShop – Yuvomi module

**DE:** Dieser Ordner ist das Browser-Modul. Er wird als `modules/flessinglabs-quickshop` in Yuvomi eingebunden und braucht den QuickShop-Katalogdienst unter `/api/extensions/flessinglabs-quickshop`. Installation: README.de.md im Hauptordner des Repositorys.

**EN:** This folder is the browser module. It goes into Yuvomi as `modules/flessinglabs-quickshop` and needs the QuickShop catalogue service at `/api/extensions/flessinglabs-quickshop`. Installation: README.md in the repository root.
