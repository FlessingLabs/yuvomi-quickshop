# FlessingLabs QuickShop – Yuvomi-Modul

Dieser Ordner ist das Browser-Modul. Er wird als `modules/flessinglabs-quickshop` in Yuvomi eingebunden.
Das Modul braucht den QuickShop-Katalogdienst unter `/api/extensions/flessinglabs-quickshop`.
Installation und Einrichtung stehen in der README im Hauptordner des Repositorys.
